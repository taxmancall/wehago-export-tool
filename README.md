# 위하고 수출매출 업로드 생성기

국세청(홈택스) 수출신고내역, 외국환은행 환율 파일, 위하고 직전 양식을 끌어다 놓으면
위하고 업로드용 매출 엑셀을 만들어 주는 단일 HTML 파일입니다.

## 사용법
1. `index.html`을 브라우저(크롬 권장)로 엽니다. 처음 열 때 인터넷 연결이 필요합니다(라이브러리 CDN).
2. ① 외국환은행 환율, ② 수출신고내역(홈택스), ③ 위하고 직전 양식을 각 칸에 끌어다 놓습니다.
3. 선택: 업체 면장 압축파일(.zip)을 올리면 거래처명과 면장 대조가 추가됩니다.
4. [처리 시작] → 검증 표 확인 → 위하고 업로드 파일 받기.

## 처리 기준
- 환율: 선적일 기준 매매기준율, 주말·공휴일은 직전 영업일
- 원화: 외화 × 환율, 원 미만 절사
- 부가세 열은 공란, 과세유형 16 / 기본계정 401 / 상대계정 108 (직전 양식 기준)

## 주의
- 모든 처리는 브라우저 안에서만 이루어집니다. 파일은 외부로 전송되지 않습니다.
- 실제 고객 자료(엑셀, PDF, 업로드 결과물)는 이 저장소에 올리지 마세요. 이 저장소에는 도구 파일만 둡니다.
